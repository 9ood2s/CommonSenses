# 생성형 생활 모습 이미지 프롬프트 기록

공통 스타일은 `hand-drawn 2D educational adventure animation`, `clean ink outlines`, `crisp cel shading`, `broad readable color shapes`로 고정했다. 모든 프롬프트에 사진 같은 피부와 조명, 동일한 미형 얼굴, 현대 물건과 후대 복식을 피하도록 명시했다.

## `paleolithic-mobile-camp.png`

기준 장면의 바위 그늘, 가죽 바람막이, 불, 주먹도끼 제작, 가죽 긁기, 열매·뿌리 채집, 돌촉 창을 유지한 채 전체를 2D 모험 애니메이션풍으로 변환. 어린이·성인·노인과 키·체구·얼굴형이 서로 다른 인물을 배치하고, 금속·토기·농경·한복·판타지 장비를 제외.

## `neolithic-riverside-village.png`

강가·바닷가의 움집 마을, 조·기장 밭, 끈으로 묶은 간석기 괭이, 그물과 물고기, 조개 채집, 갈돌과 갈판, 가락바퀴, 땅과 돌로 고정한 빗살무늬토기를 유지한 채 2D 셀 애니메이션풍으로 변환. 금속과 벼농사, 후대 건축·복식을 제외.

## `bronze-age-rice-dolmen-ritual.png`

벼 수확, 곡식 저장, 고인돌 공동 축조, 울타리와 지배자의 의례를 한 화면에 구성. 농부의 도구는 손에 직접 쥐는 회색·갈색 반달돌칼과 돌날을 끈으로 묶은 나무 도구로 표현하고, 청동은 지도자의 의례용 물건과 소수의 권위 물건에만 사용. 은빛 쇠낫과 철제 농기구를 제외.

## `gojoseon-law-grain-compensation.png`

성장한 방어 취락의 공개적인 분쟁 조정 장면에서 다친 사람에게 곡식으로 배상하는 모습을 중심에 배치. 경비 인물의 무기는 짧고 넓으며 녹청이 있는 비파형 동검 한 점으로 제한하고, 뒤편 작은 작업장에 철기 수용을 암시. 처벌의 폭력, 악인 외모 고정관념, 왕궁·왕관·후대 장검을 제외.

## `bangudae-coastal-life.png`

암각화에서 추론한 선사 시대 해안과 강 어귀를 배경으로 바위에 고래·사슴·배를 새기는 사람, 그물과 밧줄을 손질하는 가족, 작살과 노를 든 공동체, 수면에 떠오른 고래와 배의 협동 장면을 구성. 피와 사냥 성공 장면은 피하고 배·그물·작살·협력을 읽을 수 있게 표현.
