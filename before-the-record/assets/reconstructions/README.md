# 생활 모습 재구성 이미지

이 폴더에는 선사 시대와 고조선의 생활 모습을 학습용으로 재구성한 생성형 이미지를 둔다.

## 공통 제작 원칙

- 모든 화면에 `생활 모습 재구성 이미지`라고 표시한다.
- 지도서와 실제 유물·유적에서 확인되는 범위를 벗어난 소품을 넣지 않는다.
- 특정 개인의 실제 초상처럼 표현하지 않는다.
- 인물을 미화하거나 모두 같은 얼굴과 체형으로 그리지 않는다.
- 어린이, 성인, 노인이 함께 등장하며 마른 체형, 다부진 체형, 큰 체격, 작은 체격을 고르게 배치한다.
- 햇볕에 그을린 피부, 거친 머리카락, 작업으로 닳은 손과 옷 등 생활감을 살린다.
- 체형, 나이, 얼굴 생김새를 선악이나 능력과 연결하지 않는다.
- 일본 애니메이션풍의 일관된 화풍을 사용하되 아이돌형 외모, 현대식 미용, 과도하게 깨끗한 의상은 피한다.
- 생성 이미지 속 유물은 학습 개념을 보여 주는 재구성일 뿐, 실제 소장품 사진을 대신하지 않는다.

## 확보한 장면

- `paleolithic-mobile-camp.png`: 구석기 시대의 이동 생활, 뗀석기 제작, 불, 사냥과 채집, 임시 거처
- `neolithic-riverside-village.png`: 신석기 시대의 강가·바닷가 정착 마을, 조·기장 재배, 물고기잡이, 빗살무늬토기, 갈돌과 갈판, 가락바퀴
- `bronze-age-rice-dolmen-ritual.png`: 청동기 시대의 벼 수확, 반달돌칼, 곡식 저장, 고인돌 축조, 지배자의 의례
- `gojoseon-law-grain-compensation.png`: 고조선의 성장한 취락, 곡식 배상으로 표현한 법, 비파형 동검, 철기 수용
- `bangudae-coastal-life.png`: 반구대 암각화에서 추론한 배, 그물, 작살, 고래잡이와 협동

다섯 장 모두 2D 셀 애니메이션풍으로 제작했다. 사진처럼 사실적인 피부·조명보다 또렷한 선, 단순한 색면, 읽기 쉬운 행동을 우선했다.
