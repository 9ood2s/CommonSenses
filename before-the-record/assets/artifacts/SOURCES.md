# 실제 유물·유적 이미지 출처

이 폴더의 사진은 생성 이미지가 아니다. 각 소장 기관이 공개한 실제 유물·유적 사진을 원본 비율로 사용한다.

웹 화면에서는 다음을 함께 표기한다.

- 유물·유적의 정확한 명칭
- 시대와 출토지 또는 소재지
- 소장·관리 기관
- 출처 페이지 링크
- 공공누리 이용 유형

사진과 생성형 생활 장면을 합성하거나, 사진 속 유물을 생성 이미지로 대체하지 않는다.
