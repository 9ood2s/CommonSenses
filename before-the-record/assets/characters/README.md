# Character illustrations

These two project assets were created with the built-in image-generation tool for the `BEFORE THE RECORD` web lesson.

## `player-curator.png`

- Use: player portrait, story dialogue, duel HUD, and success result
- Prompt summary: Korean upper-elementary museum apprentice curator; ordinary child proportions; expressive visible face; navy field jacket, amber hoodie, artifact scanner and magnifying lens; polished 2D cel-animation style; transparent background; no text or watermark

## `zero-archive-ai.png`

- Use: title antagonist, story dialogue, duel arena and HUD, and failed result
- Prompt summary: smug floating archive AI with a ring-shaped CRT head, asymmetric LED expression, cursor hands, filing-cabinet body, receipt tail, buffering halo, glitch fragments and orbiting evidence cards; playful AI-meme energy without copying an existing meme or mascot; polished 2D cel-animation style; transparent background; no text or watermark

Both PNG files are 1024 × 1536 with an alpha channel.
